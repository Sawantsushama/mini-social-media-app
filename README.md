# MiniSocial — Task 2

A ready-to-run mini social media platform using:

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite
- bcryptjs
- Express Session

## Features

- Register and login
- User profiles
- Edit bio
- Create posts
- Delete own posts
- Like/unlike posts
- Comments
- Follow/unfollow users
- Followers/following counts
- Responsive UI
- SQLite database

## Requirements

Install Node.js 18+.

## Run

Open a terminal in this folder:

```bash
npm install
npm start
```

Then open:

http://localhost:3000

## Demo

Create two accounts in two browser windows/tabs to test the follow system.

The SQLite database (`social.db`) is created automatically on first run.

## Important

This is a college/demo project. Before deploying publicly, use a strong session secret, HTTPS, production session storage, CSRF protection, rate limiting, and other production security measures.
